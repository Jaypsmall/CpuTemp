## ✨ Características principales

* **⚡ Selector de gobernador avanzado  (Root):** Ajusta el comportamiento de la CPU en tiempo real mediante tres perfiles de energía dedicados:

* **🔴 Boost:** Activa el gobernador de alto rendimiento (*Performance*) para maximizar la velocidad del procesador durante tareas exigentes o juegos.

* **🟢 Normal:** Configura el gobernador equilibrado (*Interactive/Schedutil*) para optimizar la relación potencia-rendimiento en el uso diario.

* **🔵 Cool:** Fuerza un estado de ahorro de energía (*Powersave*) reduciendo las frecuencias para mitigar el sobrecalentamiento del dispositivo.

* **📈 Monitor de estado integrado:** Proporciona una visión general inmediata del modo activo y monitorización directa de las fluctuaciones térmicas al cambiar entre perfiles de hardware.

* **🛡️ Integración de superusuario:** Diseñado para funcionar de forma segura con gestores de permisos root modernos como Magisk y KernelSU.

 ---

## 🛠️ Arquitectura y pila técnica

* **Requisitos:** Se requiere acceso de superusuario (root) para manipular los nodos del kernel ubicados en `/sys/devices/system/cpu/`.

* **Seguridad:** Código de nivel de producción optimizado y protegido contra ingeniería inversa mediante técnicas avanzadas de ofuscación (**R8 / ProGuard**).
